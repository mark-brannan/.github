# Support

This is the default support policy for repositories under this account
that don't define their own.

These are spare-time projects with no support contract and no SLA. For a
question, a bug, or a feature request, please open a public issue on the
relevant repository. There's no guaranteed response time, but issues do
get read.

For a security vulnerability, see [SECURITY.md](SECURITY.md) instead —
don't report it as a regular issue.
