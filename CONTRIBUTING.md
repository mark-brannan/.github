# Contributing

This is the default contributing guide for repositories under this account
that don't define their own (a repository with repo-specific contributing
instructions overrides this file, and that override is deliberate — read
its own `CONTRIBUTING.md` instead).

- PRs are welcome.
- For anything nontrivial, please open an issue first to talk through the
  approach before writing code — it saves both of us a rewrite.
- Run the repository's test suite (`npm test`, or whatever its `package.json`
  scripts define) before opening a PR, and make sure it passes.
- Keep PRs focused: one change, one PR, with a description of what and why.
- By contributing, you agree to follow this project's
  [Code of Conduct](CODE_OF_CONDUCT.md).
